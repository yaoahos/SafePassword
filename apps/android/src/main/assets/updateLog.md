# 更新日志

**2026/11/03 · 1.0.0**
- 加密存储：AES-256-GCM 加密，PBKDF2-HMAC-SHA256 派生密钥（210,000 次迭代），主密码不离开设备
- 解锁方式：主密码解锁、指纹解锁；指纹凭据保存在 Android Keystore，指纹变更或改主密码后自动失效
- 密码库管理：支持多个密码库，可新建、重命名、切换与删除
- 条目管理：内置登录、银行卡、WiFi、笔记等模板，支持自定义字段与字段类型
- 修复 切换标签、筛选或收藏/删除条目后列表没有回到顶部，被移动的条目会「跑到看不见的地方」
- 修复 导出 JSON / CSV / XML 再导入时丢失标签颜色与排序，CSV 导入还会丢掉标签本身
- 修复 秘密字段在导出导入后可能被当成普通密码字段
- 新增 设置可控制「启动时检查更新」，关闭后仍可在关于页手动检查
- 字段历史：密码与秘密字段保留历史值，可查看、复制、逐条删除或清空
- 多端同步：两端时钟不一致时也能正确合并两侧新增的条目，不再出现一端覆盖另一端的情况
- 整理与检索：标签分类、收藏、回收站、按标题或时间排序、标题与字段搜索
- 云端同步：标准 WebDAV（坚果云、Nextcloud、群晖等），多端增量合并与冲突提示
- 云端密码库：列出云端已有密码库，可直接切换或删除；被其它设备删除时提示处理
- 本地备份：加密快照，可自选保存目录，支持自动备份间隔与一键恢复
- 安全中心：弱密码、重复使用、已泄露（HIBP k-匿名查询）、长期未更新检测
- 工具与外观：密码生成器、CSV / JSON / XML 导入导出、主题配色、标签 20 色与自定义色值
- 应用更新：内置检查更新、下载与安装
- 界面适配：手机、平板与横屏布局
