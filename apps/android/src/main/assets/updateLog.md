# 更新日志

**2026/11/20 · 1.1.6**
- 变更：统一应用标识与云端文件命名
- 变更：本版包名与旧版不同，可与旧版同时安装；两版数据互不共享，旧版密码库需先导出再在本版导入
- 变更：请勿让新旧两版同时开启自动同步并连接同一 WebDAV 目录，避免互相同步同一批文件产生覆盖或冲突
- 优化：提升跨版本数据兼容性

**2026/11/16 · 1.1.5**
- 变更：关于页使用应用图标，点击图标或标题跳转项目仓库
- 变更：取消顶栏同步按钮，首页与收藏页改用下拉刷新触发同步
- 修复：收藏页返回时先回到全部条目
- 修复：Android 12/13 动态取色未生效
- 修复：壁纸主色无效时动态取色发灰，改选候选色中的可用值
- 修复：壁纸色不可用时未沿用已选主题色，补充回退提示
- 优化：换壁纸后主色实时更新，无需返回应用

**2026/11/15 · 1.1.4**
- 修复：冷启动时把清理过期删除记录当成本地改动，每次启动都整库重传
- 修复：冷启动必判「云端有更新」，每次启动都下载一整包
- 优化：自动同步没有变化时不再刷新同步状态

**2026/11/14 · 1.1.3**
- 新增：主题支持跟随桌面壁纸动态取色，换壁纸后回到应用即更新
- 新增：主题页支持输入色号自定义颜色，输入即时预览，点「应用」生效
- 变更：动态取色开启时选择任意颜色会自动关闭动态取色
- 修复：深色模式下主题页输入框边框不可见、主色容器文字与冷色主题撞色

**2026/11/14 · 1.1.2**
- 修复：只有附件发生变化的条目在同步时被当成没改动，另一端的附件更新丢失
- 修复：两端在同一毫秒修改同一条目时漏判冲突，一侧内容被直接覆盖
- 修复：两台设备几乎同时上传不同密码库时，云端列表少一个库（文件还在但列表里看不到）
- 修复：同步途中被自动同步打断，可能留下「库文件已更新、清单未登记」的中间状态
- 修复：同步被取消后界面停在「正在同步…」，自动拉取从此不再触发
- 优化：判断哪边有改动改用整库内容指纹，不再比较两端设备的时间，时钟不准也不会误判

**2026/11/13 · 1.1.1**
- 变更：删除密码库只删除本机文件，云端副本保留，误删可随时从云端重新下载
- 新增：云端密码库列表显示已下载到本机的库，可就地删除云端那一份（不影响本机）
- 修复：解锁界面无法使用系统返回退出应用，返回键与左缘右滑手势均无响应

更早的版本与完整日志见 Releases。
