# 更新日志

**2026/10/31 · 1.3.0**
- 新增 自动拉取云端更新，可选关闭、30 秒、1 分钟、5 分钟；解锁后与回到前台时也会各检查一次
- 新增 删除以墓碑方式同步，彻底删除的条目不会再被云端旧数据复活
- 优化 密码库默认按创建时间排序，标题支持中文拼音排序，点击可切换升序与降序
- 优化 排序菜单用主题色标出当前方式，选中后自动关闭，副标题只保留条目数
- 优化 指纹解锁改用系统密钥保护主密码，凭据不再以明文保存
- 优化 默认禁止截屏与最近任务预览，复制的密码标记为敏感内容
- 优化 更新安装只接受应用自己下载的安装包；WebDAV 登录凭据只发送到所配置的服务器
- 修复 修改主密码后指纹凭据仍然有效的问题，现在会失效并要求重新开启
- 修复 密码库文件被篡改时读取可能异常的问题

**2026/10/31 · 1.2.0**
- 优化 安装包体积大幅减小，下载与安装更快
- 优化 网络策略集中到显式配置文件，行为不变，便于审计
- 修复 自动锁定后重新打开时，指纹验证偶尔不弹出的问题
- 优化 「关于」页中间的标题可直接点击打开项目开源地址

**2026/10/30 · 1.1.0**
- 新增 检查更新与自更新，可在通知栏查看下载进度，下载完成后直接安装
- 新增 「关于」页与侧边栏软件名处的检查更新入口，更新日志随包内置、离线可看
- 新增 秘密字段类型，与密码一样默认隐藏，但不参与弱密码、重复密码与泄露检测
- 优化 页面切换动画：标签页淡入缩放，层级页面左右滑动，返回时方向相反
- 优化 同步状态提示 3 秒后自动消失，常驻显示上次同步时间
- 修复 从安全中心进入条目编辑后，保存会跳回首页的问题

**2026/10/29 · 1.0.0**
- 新增 密码库创建、恢复与解锁，支持主密码和指纹两种方式
- 新增 条目、标签、自定义字段、图标、搜索、收藏、回收站与批量操作
- 新增 WebDAV 云端同步，支持保存后自动同步与冲突合并
- 新增 CSV、JSON 与 SafeInCloud XML 导入导出
- 新增 密码生成器、安全检查与泄露检测
- 新增 主题配色、自动备份，以及手机、平板、横屏适配
