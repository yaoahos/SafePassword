# 更新日志

**2026/11/12 · 1.0.6**
- 新增 动态验证码字段支持扫码录入：可直接对着网站给出的二维码扫，也能从相册选一张二维码截图识别
- 新增 页面转场与手机端一致的水平推入动画；从屏幕左边缘右滑可返回上一页
- 优化 顶部提示条宽度随提示内容自适应，不再固定占满整行；连续两条提示会依次显示，不再互相覆盖
- 优化 在某个标签分类下新建条目时，默认就带上该标签
- 优化 冷启动不再先闪一下深色背景，启动更跟手
- 优化 应用内更新日志最多显示 5 个版本
- 优化 下载更新包后先校验包名与签名；明文导出（JSON/CSV/XML）前增加风险确认
- 变更 移除「多行文本」字段类型（已有条目里的多行字段仍照常显示与编辑），动态验证码移到类型列表最后

**2026/11/12 · 1.0.5**
- 新增 TOTP 认证器字段：可保存网站给出的 otpauth:// 链接或 Base32 密钥（密钥文件码），详情页实时生成 6 位动态码并支持一键复制，可作 GitHub 等双因素登录的认证器
- 新增 应用内提示改为顶部彩色提示条（成功/错误/警告/信息四态），自动消失、点一下即关；弹窗错误提示改为彩色行内提示条
- 修复 输入主密码等输入框被输入法遮挡的问题（含创建密码库、WebDAV 恢复等弹窗）
- 修复 小米换机等场景后无法保存 WebDAV 密码：加密配置失效时自动重建（只重置本机设置，密码库不受影响）
- 优化 WebDAV 服务器地址留空保存时自动填入坚果云地址并回显，按钮不再因留空禁用
- 变更 文件字段不再支持预览（任何文件），保留导出到本地

**2026/11/12 · 1.0.4**
- 新增 文件字段，可保存单个 50KB 以内的小文件，随密码库加密与同步
- 新增 WebDAV 同步页密码框支持显示/隐藏
- 优化 添加、编辑字段弹窗的样式与类型选择
- 修复 切换底部标签时顶栏与底栏抖动
- 修复 指纹传感器异常时无法关闭指纹解锁，检测到硬件损坏自动关闭
- 变更 应用签名密钥已重新生成

**2026/11/05 · 1.0.3**

- 修复 从云端恢复或导入密码库后沿用上一个库的标签筛选，首页显示 0 个条目
- 修复 按时间排序与桌面端顺序相反（时间戳相同时两端并列顺序不一致）

**2026/11/05 · 1.0.2**
- 优化 启动检查到新版本时弹出更新框，在解锁进入首页后提示
- 修复 首页与 WebDAV 页的同步状态互相串页
- 修复 页面内已有同步状态时仍重复弹出底部提示
- 修复 检查更新偶发失败，并区分限流与网络错误
- 优化 检查更新与桌面端一致：失败原因分开提示，下载时校验安装包来源与内容

**2026/11/04 · 1.0.1**

**2026/11/03 · 1.0.0**
- 加密存储：AES-256-GCM 加密，PBKDF2-HMAC-SHA256 派生密钥，主密码不离开设备
- 解锁方式：主密码解锁、指纹解锁；指纹凭据保存在 Android Keystore，指纹变更或改主密码后自动失效
- 密码库管理：支持多个密码库，可新建、重命名、切换与删除
- 条目管理：内置登录、银行卡、WiFi、笔记等模板，支持自定义字段与字段类型
- 字段历史：密码与秘密字段保留历史值，可查看、复制或逐条删除
- 整理与检索：标签分类、收藏、回收站、按标题或时间排序、标题与字段搜索
- 云端同步：标准 WebDAV，多端增量合并与冲突提示
- 云端密码库：列出云端已有密码库，可直接切换或删除；被其它设备删除时提示处理
- 本地备份：加密快照，可自选保存目录，支持自动备份间隔与一键恢复
- 安全中心：弱密码、重复使用、已泄露、长期未更新检测
- 工具与外观：密码生成器、CSV / JSON / XML 导入导出、主题配色、标签 20 色与自定义色值
- 应用更新：内置检查更新、下载与安装
- 界面适配：手机、平板与横屏布局
